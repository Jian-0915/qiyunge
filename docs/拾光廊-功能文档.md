# 拾光廊 — 图库模块功能文档

## 一、模块概述

拾光廊是 QiyunGe 应用的图库管理模块，提供本地图片管理、在线图片搜索、图集组织、批量操作等完整功能。与听雨轩（音乐模块）保持一致的分层架构和视觉风格。

**架构分层**：`Entity → Repository → Service → ViewModel → View`

**涉及文件**：20 个（2 Entity + 4 Repository + 4 Service + 1 ViewModel + 7 View + 1 SQL + 1 CSS）

### 3.1 光影墙（allImages）

主页面，展示所有本地图片。

- **搜索框**：实时搜索，按标题/分类模糊匹配
- **排序选择**：ChoiceBox，5 种排序方式
- **视图切换**：▦ 网格视图 / ☰ 列表视图
- **分类标签栏**：全部 / 风景 / 自然 / 美食 / 人物 / 建筑
- **批量操作栏**：选中图片后显示，支持批量收藏/删除/加入图集
- **图片网格**：FlowPane，每个图片为 ImageCard（200×220）
- **图片列表**：TableView，含标题/分类/大小/分辨率/上传时间列，双击查看详情
- **空状态**："廊中无影"，带"上传图片"和"探索在线图片"按钮
- **拖拽上传**：支持拖拽图片文件到内容区

### 3.2 风物卷（categories）

按分类浏览图片。

- **分类卡片网格**：每个分类一张卡片（160×120），含图标 + 名称 + 数量统计
- **点击分类**：跳转到光影墙并自动筛选该分类

### 3.3 择景（favorites）

收藏图片展示。

- **收藏图片网格**：展示用户收藏的所有图片
- **空状态**："尚未择景"

### 3.4 图集（albums）

图集管理，索引/详情视图互斥切换。

- **索引视图**：
  - 择景项（置顶，红色 ♥ 图标）
  - 图集列表（♪ 图标 + 名称 + 数量 + 删除按钮）
  - 新建图集按钮
- **详情视图**：
  - 返回按钮 + 图集名称 + 图片数量
  - 图片网格
  - 空状态

### 3.5 在线寻图（onlineSearch）

在线图片搜索。

- **搜索框 + 搜索按钮**
- **平台筛选 Tab**：全部 / 各平台 ToggleButton
- **在线图片网格**：展示搜索结果，每张图片含来源标识和下载按钮
- **下载**：将在线图片下载到本地图库
- **收藏**：将在线图片保存并标记收藏
- **空状态**："未寻得"

### 3.6 图库设置（settings）

- **默认分类**：ChoiceBox，持久化到 ConfigStorage
- **缓存管理**：异步计算缩略图缓存大小 + 清理缓存按钮
- **图片质量偏好**：ChoiceBox（高质量/标准/低质量），持久化到 ConfigStorage

## 五、架构详解

### 5.1 Entity 层

| 类 | 说明 |
|----|------|
| `GalleryImage` | 图片实体，含 id/title/category/url/localPath/thumbnailUrl/width/height/fileSize/source/createdAt/favorited |
| `ImageAlbum` | 图集实体，含 id/name/description/coverImageId/createdAt/imageCount(瞬态) |

### 5.2 Repository 层

| 类 | 核心方法 |
|----|----------|
| `GalleryImageRepository` | findAll, findByCategory, findById, search, create, delete, countAll, countByCategory |
| `ImageAlbumRepository` | findAll(LEFT JOIN 统计图片数), findById, create, update, delete, countAll |
| `ImageAlbumItemRepository` | addItem(INSERT OR IGNORE 去重), removeItem, findImagesByAlbumId, findImageIdsByAlbumId, countByAlbum, isInAlbum, findAlbumIdsByImageId |
| `UserImagePreferenceRepository` | addPreference, removePreference, isPreferenced, findFavoriteImageIds, countByUser |

### 5.3 Service 层

| 类 | 职责 |
|----|------|
| `GalleryService` | 图库核心业务服务，整合图片 CRUD、收藏管理、图集管理、批量操作、上传（含宽高提取+缩略图生成） |
| `OnlineImageService` | 在线图片搜索统一入口，多平台搜索+去重+缓存（ConcurrentHashMap, TTL 30 分钟） |
| `ImageProvider` | 图片源提供者接口，定义 getProviderId/getProviderName/search/resolveDownloadUrl/supports |
| `UnsplashProvider` | Unsplash API 实现，JDK HttpClient 调用，手动 JSON 解析（不依赖外部库） |

### 5.4 ViewModel 层

`GalleryViewModel` 管理 4 个 ObservableList 和 4 个 Property：

| 属性 | 类型 | 用途 |
|------|------|------|
| `images` | ObservableList\<GalleryImage\> | 当前图片列表（光影墙/择景共用） |
| `albums` | ObservableList\<ImageAlbum\> | 图集列表 |
| `albumImages` | ObservableList\<GalleryImage\> | 图集内图片 |
| `onlineImages` | ObservableList\<GalleryImage\> | 在线搜索结果 |
| `selectedCategory` | StringProperty | 当前选中分类 |
| `searchKeyword` | StringProperty | 搜索关键词 |
| `errorMessage` | StringProperty | 错误/状态信息 |
| `loading` | BooleanProperty | 加载状态 |

### 5.5 View 层

| 类 | 职责 |
|----|------|
| `GalleryView` | 主视图，BorderPane 三栏布局，7 个导航页面 |
| `GallerySidebar` | 侧边导航栏，7 个导航项 |
| `GalleryHeader` | 顶部标题栏 |
| `GalleryEmptyState` | 空状态组件，5 种诗意化空状态 + 回调按钮 |
| `ImageCard` | 图片卡片，StackPane，支持点击/Ctrl+点击/收藏 |
| `ImageDetailDialog` | 图片详情弹窗，大图+信息+翻页 |
| `AlbumDialog` | 新建图集对话框，名称+描述 |

## 六、核心交互流程

### 6.1 图片上传

```
用户拖拽/点击上传 → GalleryView.handleUpload()
  → GalleryViewModel.uploadImage(file, category, title)
    → GalleryService.uploadImage()
      → 校验格式(JPG/PNG/WEBP/GIF)
      → 复制文件到 galleryDir
      → JavaFX Image 提取宽高
      → 生成缩略图到 thumbnails/
      → GalleryImageRepository.create() 入库
    → 刷新图片列表
```

### 6.2 在线搜索

```
用户输入关键词 → GalleryView.showOnlineSearch()
  → GalleryViewModel.searchOnline(keyword)
    → OnlineImageService.search(keyword)
      → 遍历所有 ImageProvider
        → UnsplashProvider.search() → HttpClient 调用 Unsplash API
      → 按 source+url 去重
      → 缓存结果（30 分钟 TTL）
    → 更新 onlineImages ObservableList
  → UI 自动刷新图片网格
```

### 6.3 批量操作

```
用户 Ctrl+点击多选图片 → ImageCard.setSelected(true)
  → 批量操作栏自动显示
  → 点击"批量收藏/删除/加入图集"
    → GalleryViewModel.batchFavorite/batchDelete/batchAddToAlbum()
      → GalleryService 对应方法
        → 批量操作数据库
      → 刷新图片列表
```

### 6.4 图集管理

```
新建图集 → AlbumDialog → GalleryViewModel.createAlbum()
  → GalleryService.createAlbum() → ImageAlbumRepository.create()

查看图集 → 点击图集索引项 → 切换到详情视图
  → GalleryViewModel.loadAlbumImages(albumId)
    → GalleryService.getAlbumImages() → ImageAlbumItemRepository.findImagesByAlbumId()

添加图片到图集 → 批量操作"加入图集" → ChoiceDialog 选择图集
  → GalleryViewModel.batchAddToAlbum(albumId, images)
    → GalleryService.batchAddToAlbum() → ImageAlbumItemRepository.addItem()
```

## 七、技术要点

### 7.1 异步编程

所有耗时操作（数据库查询、网络请求、文件操作）通过 `AsyncExecutor` 在后台线程执行，UI 更新通过 `Platform.runLater()` 回到 JavaFX 应用线程。

### 7.2 缓存策略

- **在线搜索缓存**：`ConcurrentHashMap<String, List<GalleryImage>>`，TTL 30 分钟
- **缩略图缓存**：本地文件系统 `thumbnails/` 目录，设置页可查看大小和清理

### 7.3 配置持久化

通过 `ConfigStorage` 存储用户偏好：
- `galleryDefaultCategory` — 默认分类
- `galleryThumbnailQuality` — 缩略图质量

### 7.4 在线图片源扩展

`ImageProvider` 接口支持扩展新的图片源：
1. 实现 `ImageProvider` 接口
2. 在 `AppContext` 中调用 `onlineImageService.registerProvider(new XxxProvider())`
3. 平台筛选 Tab 自动显示新平台

### 7.5 图片格式支持

上传支持：JPG / JPEG / PNG / WEBP / GIF

## 八、已知限制

| 项目 | 说明 |
|------|------|
| Unsplash API Key | 当前为占位符 `your-unsplash-access-key`，需替换为真实 Key 才能使用在线寻图 |
