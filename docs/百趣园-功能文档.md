# 百趣园 — 娱乐模块功能文档

## 一、模块概述

百趣园是 QiyunGe 应用的休闲娱乐模块，面向个人用户，提供碎片化、低门槛的趣味小游戏和实用小工具。定位为"随时玩一把随时停"的轻松空间，与栖云阁整体诗意风格保持一致。

**设计原则**：
- 个人自用，无社交/排行/对战需求
- 零压力：无惩罚机制，所有记录均为自我激励
- 短时长：单次体验 1-5 分钟可完成
- 诗意命名：功能名称与栖云阁风格统一

│ （侧边    │                                       │

│ ☁趣味坊  │  │ 点击卡片进入游戏                   │  │

│          │  ┌─ 趣迹 ───────────────────────────┐  │
│          │  │ 各游戏最佳成绩列表                 │  │
│          │  │ 成就徽章展示                       │  │
│          │  └───────────────────────────────────┘  │

### 3.1 游乐场（games）

游戏入口页面。

- **游戏卡片网格**：每个游戏一张卡片，含图标 + 名称 + 最佳成绩摘要
- **点击卡片**：切换到对应游戏内页
- **空状态**：暂无

### 3.2 趣味坊（tools）

趣味工具入口页面。

- **工具卡片网格**：每个工具一张卡片，含图标 + 名称 + 简要说明
- **点击卡片**：切换到对应工具内页（求签/问卜弹出对话框，专注计时内嵌展示）

### 3.3 趣迹（records）

个人记录页面。

- **最佳成绩列表**：按游戏分组，展示每个游戏的最佳成绩
- **成就徽章**：网格展示已获得的徽章，未获得的灰色显示

### 3.4 游戏内页

各游戏/工具的详细页面，统一布局：

- **返回按钮** + 游戏名称
- **游戏主区域**：各游戏核心交互区
- **成绩区**：当前成绩 / 历史最佳
- **操作按钮**：再来一局 / 重置

## 四、各功能详细设计

### 4.1 猜数（GuessNumber）

| 项目 | 说明 |
|------|------|
| 玩法 | 系统随机生成 1-100 的整数，用户输入猜测，系统提示"大了"或"小了"，直到猜中 |
| 难度 | 可选范围：1-100（简单）/ 1-500（普通）/ 1-1000（困难） |
| 记录 | 最少步数（按难度分别记录） |
| 结束 | 猜中后显示祝贺信息和步数，可与最佳成绩对比 |

### 4.2 翻牌（MemoryFlip）

| 项目 | 说明 |
|------|------|
| 玩法 | N×N 方格，背面朝上，每次翻两张，配对成功保持正面，失败翻回，直到全部配对 |
| 难度 | 4×4（8 对）/ 6×6（18 对） |
| 记录 | 最少翻牌次数（按难度分别记录） |
| 图案 | 使用栖云阁主题图标/符号作为牌面图案 |

### 4.3 华容道（SlidingPuzzle）

| 项目 | 说明 |
|------|------|
| 玩法 | N×N 方格，1 个空位，点击相邻方块滑动，目标是将数字按顺序排列 |
| 难度 | 3×3（1-8）/ 4×4（1-15） |
| 记录 | 最少步数和最短时间（按难度分别记录） |
| 打乱 | 随机打乱（保证可解），打乱步数随难度增加 |

### 4.4 求签（DailyFortune）

| 项目 | 说明 |
|------|------|
| 玩法 | 点击"求签"，随机展示一条签文 |
| 规则 | 同一天内结果固定（基于日期+用户ID的种子），次日刷新 |
| 签文 | 包含：签号、签诗（七言四句）、解签（一句话解读）、运势等级（上上/上/中/下/下下） |
| 收藏 | 可收藏签文，历史签文可在趣迹中查看 |

### 4.5 问卜（RandomChoice）

| 项目 | 说明 |
|------|------|
| 玩法 | 输入 2-10 个选项（文本），点击"天意"，随机选中一个并高亮展示 |
| 动画 | 选项快速轮转闪烁后定格，增加仪式感 |
| 记录 | 不记录，纯即用即走 |

### 4.6 专注计时（Pomodoro）

| 项目 | 说明 |
|------|------|
| 模式 | 25 分钟专注 + 5 分钟短休息，每 4 轮后 15 分钟长休息 |
| 显示 | 圆形进度环 + 剩余时间 + 当前轮次 |
| 联动 | 可选择听雨轩中的播放列表作为专注背景音乐，休息时自动暂停 |
| 统计 | 今日专注总时长、连续专注天数 |

### 4.7 每日一题（DailyQuiz）

| 项目 | 说明 |
|------|------|
| 玩法 | 每天一道选择题（4 选 1），涵盖历史/科学/文学/地理等 |
| 规则 | 每天仅一次作答机会，答后显示正确答案和解析 |
| 记录 | 连续答对天数、累计答对题数 |
| 题源 | 内置题库，按日期轮转，保证每天不重复 |

### 4.8 接龙（IdiomChain）

| 项目 | 说明 |
|------|------|
| 玩法 | 系统出首成语，用户输入同音字开头的成语，系统再接，如此往复 |
| 规则 | 同音即可（不限声调），30 秒内未接上则结束 |
| 记录 | 最长接龙轮数 |
| 词库 | 内置常用成语词库（约 3000 条） |

## 七、技术要点

### 7.1 架构分层

沿用栖云阁统一架构：`Entity → Repository → Service → ViewModel → View`

### 7.2 签文日期固定算法

使用 `日期字符串 + 用户ID` 作为随机种子，保证同一天内求签结果固定：
```
seed = hash(userId + "-" + LocalDate.now().toString())
fortuneIndex = seed % fortunePool.size()
```

### 7.3 题库管理

- 内置 JSON 题库文件，按分类组织（历史/科学/文学/地理）
- 每日选题算法：`hash(userId + "-" + date) % totalQuestions`，保证每天不重复
- 后续可扩展在线题库

### 7.4 成语词库

- 内置约 3000 条常用成语，含拼音首字母索引
- 接龙匹配：按最后一个字的拼音首字母查找

### 7.5 专注计时与听雨轩联动

- 专注开始时，可指定听雨轩的播放列表
- 通过 AppContext 获取 MusicPlayerService 实例控制播放/暂停
- 专注阶段播放，休息阶段暂停

### 7.6 数据库迁移

新增 V6 迁移脚本，包含上述 5 张表的建表语句和索引。
